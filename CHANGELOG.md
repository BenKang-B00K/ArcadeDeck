# Changelog

All notable changes to ArcadeDeck are documented here.

## Versioning

`vMAJOR.MINOR.PATCH`

- **MAJOR** (`v+1.0.0`) — major update: new systems, breaking saves, big content drops, new game added.
- **MINOR** (`v0.+1.0`) — minor update: new features, UI/UX changes, non-breaking additions, existing game updated.
- **PATCH** (`v0.0.+1`) — balance update: stat/number tuning, bug fixes
