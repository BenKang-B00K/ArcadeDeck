Save as public/images/blog/<slug>-poster|mid|final.webp (1600×900), then run node scripts/optimize-images.cjs --blog (1600w + 800w srcset + poster 1200×630 -og crop for og:image) and node scripts/apply-blog-art.mjs (inserts poster / mid / final with alt, srcset, width/height; poster = LCP, eager + fetchpriority high), then npm run build (og:image size tags, JSON-LD ImageObjects, image sitemap, RSS enclosure, poster preload).

Favicon post-processing
  • Export the master at 1024, then downscale (nearest-neighbor for crisp pixels, or Lanczos) to 512, 192, 180 (apple-touch). Use the tiny version (#2) for 16 and 32 px.
  • Deliver PNG for apple-touch (180×180, no transparency), favicon.ico (16 + 32 + 48) and favicon-32.png. Keep WebP for the manifest.
  • Replace icon-192x192.webp, icon-512x512.webp and the OG image in public/images/.
  • Wire up: <link> tags in index.html, the manifest purpose: "maskable" entry in vite.config.ts, and the .ico.
Mascot: transparent background + page use
  • Use a tool with real alpha output: GPT Image with background: transparent, Recraft, or Ideogram's transparent mode. Midjourney and Flux cannot, so generate on a flat #00ff00 chroma-green backdrop and remove it with rembg or remove.bg, then inspect edges on a dark page and a light page.
  • Check for fringing: a halo of green or white around the silhouette means re-cut it. Keep the character's own glow inside the silhouette.
  • Export 1024 PNG as the master, ship WebP with alpha at 512 px (about 20 to 40 KB each, -q 80 --alpha_q 90), name it mascot-<pose>.webp in public/images/mascot/.
  • On pages: absolutely positioned, pointer-events: none, aria-hidden with alt="", 8 to 15% opacity when behind text, full opacity only in corners and empty areas. Lazy-load and hide below 640 px.
  • Pose by page: wave = Home, play = game pages, cheer = My Games record, confused = search and 404, sleep = offline, peek-left and peek-bottom = page edges and footer, point = call to action, card = featured, think = tips, sad = error, fly = scroll-to-top, thumbs = success.
Workflow
  • Generate one image per prompt. Check hands, text and artifacts before shipping.
  • For consistency, use Midjourney --sref <first approved image> or an image reference in Ideogram / Flux.
  • Real gameplay screenshots and short clips come first (the AdSense "aggregator look" fix). Never use AI art as a gameplay screenshot.
  • Save PNGs outside public/images/, then run scripts/optimize-images.cjs (WebP, 640w q70, -360 variant).
  • Every image gets alt (blog covers: coverImageAlt).
  • Check each tool's commercial-use terms. Disclose AI-generated art on /about or /privacy.
