# Bundled fonts

Six free fonts for the in-game font setting. All are licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org) (free to use, embed and redistribute,
including in commercial games; the fonts may not be sold on their own). The full license text of
each font is in its own folder. Files are the Latin subsets (woff2) from the Fontsource packages
(https://fontsource.org), which re-publish the original upstream releases unchanged.

| Font | Files | Copyright / author | Upstream | License file |
|---|---|---|---|---|
| Baloo 2 | `baloo-2-{400,700,800}.woff2` | © 2019 The Baloo 2 Project Authors (EkType) | https://github.com/EkType/Baloo2 | `baloo-2/LICENSE.txt` |
| Nunito | `nunito-{400,700,800}.woff2` | © 2014 The Nunito Project Authors | https://github.com/googlefonts/nunito | `nunito/LICENSE.txt` |
| Atkinson Hyperlegible | `atkinson-hyperlegible-{400,700}.woff2` | © 2020 Braille Institute of America, Inc. | https://github.com/googlefonts/atkinson-hyperlegible | `atkinson-hyperlegible/LICENSE.txt` |
| Press Start 2P | `press-start-2p-400.woff2` | © 2012 The Press Start 2P Project Authors (Reserved Font Name "Press Start 2P") | https://github.com/codeman38/PressStart2P | `press-start-2p/LICENSE.txt` |
| Bangers | `bangers-400.woff2` | © 2010 The Bangers Project Authors | https://github.com/googlefonts/bangers | `bangers/LICENSE.txt` |
| OpenDyslexic | `opendyslexic-{400,700}.woff2` | © Abbie Gonzalez (Reserved Font Name "OpenDyslexic") | https://opendyslexic.org | `opendyslexic/LICENSE.txt` |

Korean and Japanese text falls back to the system Noto Sans KR / JP (none of the six fonts cover CJK).
