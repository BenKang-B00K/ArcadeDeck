=============================================
  ArcadeDeck - 새 게임 추가 가이드
=============================================

[Step 1] 썸네일 이미지 준비
--------------------------------------------------
- WebP 형식만 사용
- public/images/ 폴더에 파일 추가
- 파일명: {slug}.webp 형태 (kebab-case 소문자)
- 예시: gem-merge.webp, my-game-banner.webp
- 큰 배너는 scripts/optimize-images.cjs로 640w q70 리사이즈

[Step 2] 두 파일 수정 (구조 + 영어 텍스트 분리)
--------------------------------------------------
new-game-template.json 의 두 블록을 각각 복사:

  (A) src/data/games.json
      └─ games_json_entry 를 배열 끝에 추가
         (id, slug, thumbnail, genres, gameUrl, aspectRatio,
          status, isOriginal, language, badge 만)

  (B) src/i18n/locales/en.json
      └─ "games" 블록 안에 en_json_games_entry 추가
         (title, description, fullDescription, controls, tips,
          lore, features 가 영어로 들어감)

규칙:
- id 는 기존 마지막 ID + 1 (문자열. 예: "22")
- slug 는 URL 경로용 영문 소문자-하이픈 (예: "galaxy-launch")
- 텍스트(title/description 등)는 games.json 에 절대 넣지 않음
- 다른 언어 파일(ko.json, ja.json, de.json 등)에는 직접 추가하지 않음
  → 영어가 fallback으로 자동 사용됨. 번역은 사용자가 별도로 진행.

[Step 3] 검증 & 빌드
--------------------------------------------------
npm run validate     ← games.json 데이터 검증만
npm run build        ← validate → sitemap → rss → tsc → vite build
                       → prerender (모든 로케일 × 모든 게임 페이지)
                       → 404.html 복사

npm run deploy       ← Firebase Hosting 배포

※ sitemap.xml, rss.xml, /play/{slug}/index.html 는 빌드 시 자동 생성.
  수동 편집 금지.
※ 다국어 prerender: 11개 로케일 × 게임 페이지 + 11개 홈 쉘 자동 생성.
  hreflang/canonical/og:locale 도 자동.

=============================================
  필드 설명 (games.json — 구조적 데이터만)
=============================================

[필수 필드]
--------------------------------------------------
id              숫자 문자열. 기존 마지막 ID + 1 (예: "22")
slug            URL 경로용 영문 소문자-하이픈 (예: "galaxy-launch")
thumbnail       썸네일 경로 ("images/{slug}.webp" 권장)
genres          장르 배열 (아래 기존 장르 목록 참고)
gameUrl         게임 iframe URL (예: "https://my-game.pages.dev/")
status          "PLAYABLE" 또는 "IN PRODUCTION"
                IN PRODUCTION 이면 사이트에 표시되지 않음

[선택 필드]
--------------------------------------------------
language        언어 배지 ("KO", "EN", "KO/EN"). 게임 자체의 인게임
                텍스트 언어를 표시. UI 다국어와 무관.
isOriginal      직접 만든 게임이면 true (Original 배지 표시)
aspectRatio     화면 비율 (기본값 "16/9". 세로형은 "9/16")
badge           "POPULAR", "NEW" 등 강조 배지

=============================================
  필드 설명 (en.json — 영어 텍스트만)
=============================================

games[id] 블록 안에:

title           영문 게임 제목
description     영문 한 줄 설명 (1~2문장. 카드/메타 description에 사용)
fullDescription 영문 상세 설명 (3~6문단 권장. 게임 페이지 본문)
controls        영문 조작법 (예: "Mouse Click: Attack / WASD: Move")
tips            영문 전략 팁 (2~4문장)
lore            영문 배경 스토리 (2~4문단)
features        특징 태그 배열 (5~8개 권장)
                ※ 모바일 지원이면 "Web & Mobile Friendly" 포함
                ※ PC 전용이면 "PC Only" 포함

=============================================
  기존 장르 목록
=============================================
Tower Defense, Clicker, Idle, Puzzle, Tycoon,
Board Game, Survival, Simulation, Roguelike,
RPG, Strategy, Casual, Arcade, Auto Battler

※ 새 장르 사용 시 validate 에서 경고. 의도적이면 무시 가능.
